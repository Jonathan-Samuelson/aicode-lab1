# מפת בדיקת מיקומים – גבעת רם (Location-review map)

An internal tool for checking and correcting the locations of the six destinations
and their pedestrian entrances before the 3D navigation app is built.
**It is not a navigation map and does not route.**

## Opening it

From the project root (`lab1/`):

```bash
python3 -m http.server 8000 --directory review
```

Then open <http://localhost:8000/> in a browser. Stop the server with Ctrl+C.

Use the local server rather than double-clicking `index.html`. The page itself works from
`file://`, but the OpenStreetMap tile servers may refuse tile requests that carry no referrer,
which would leave the background blank. The campus data layers still show without tiles.

## Using it

1. Pick a destination in the side panel. It shows its status (מאומת / נקודה משותפת / לא ידוע),
   the evidence and source links, and the candidates that were found.
2. **Building location:** press "השתמש כמיקום הבניין" on a candidate, or choose
   "מיקום הבניין" under "לחיצה על המפה תקבע" and click the map.
3. **Pedestrian entrance:** choose "כניסה להולכי רגל (הוספה)" and click the map at the door,
   on the building's outer wall. You can add several entrances. Pins can be dragged.
4. For each point, set the certainty (אומת בשטח / לפי מפה רשמית / הערכה) and a note or source.
5. Each entrance gets an **approximate link** (dashed line) to the nearest mapped pedestrian way:
   - orange = reasonable: at most 40 m, and it crosses no mapped building or fence;
   - dark red = not reasonable. The final app will show the network endpoint and say that the
     last stretch is unverified.
6. **Save:** corrections are saved automatically in this browser (localStorage).
   "ייצוא JSON" downloads `givat-ram-location-corrections.json`. The final app will read this file.
   "ייבוא JSON" loads an exported file back in.

## What the data says (OSM snapshot 2026-11-02)

| Destination | Status |
|---|---|
| בניין שפרינצק | OSM outline `way/121791888`. No mapped entrance. |
| ספריית הרמן | OSM outline `way/121168935`. No mapped entrance. |
| אולם קפלן, רוטברג | Only a shared point, `node/3705029048` "אולמות רוטברג וקפלן". No separate coordinates are made up. |
| אולם קנדה | Not in OSM. The HUJI tour booklet places it by the steps down to the Plant Evolution Garden. The unnamed buildings nearby are shown as candidates only. |
| אודיטוריום הנדסה | No source found. A300 / Rothberg A is not assumed. |

Known limitations:
- No building entrances are mapped in OSM for these destinations.
- Only one fence or wall is mapped near the campus core, so a missing fence on the map doesn't
  mean there is no fence.
- Approximate links are checked only against mapped buildings and barriers, not against
  terrain, steps or fences that aren't mapped.

## Files

- `index.html`, `review.js`, `review.css` – the page.
- `data/review-data.js` – generated by `../tools/build_review_data.py` from
  `../data/raw/osm_givat_ram_2026-11-02.json` (OSM API, bbox 35.1880,31.7690,35.2060,31.7800).
- `vendor/leaflet/` – Leaflet 1.9.4 (BSD-2-Clause).
- `tests/*.test.js` – logic tests run with stubbed DOM/Leaflet: `node review/tests/<file>`.
